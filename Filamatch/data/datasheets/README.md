# Filament data sheets

The makers' technical data sheets (TDS) for engineering filaments: a link to
each sheet and the values read from it. Filamatch uses these values for the
stiffness and strength of printed parts (see `docs/as-printed/`).

- One file per maker: `bambu_lab.json`, `polymaker.json`.
- The data sheets themselves are not in this repository: the makers own
  them. Each record links to the maker's own copy. The values are facts,
  typed in with their source, test standard and test conditions.
- The makers say their values are typical values from their own test bars,
  for reference and comparison only. A real print depends on the printer,
  the settings, the model and the conditions.

## Format

```json
{
  "schema": 1,
  "maker": "Bambu Lab",
  "accessed": "2026-11-08",
  "filaments": [
    {
      "product": "ABS",
      "type": "ABS",
      "product_url": "https://store.bambulab.com/products/abs-filament",
      "datasheet_url": "https://store.bblcdn.com/s7/default/23b4cf2b83d5470bb96d19970b5f3ae8/Bambu_ABS_Technical_Data_Sheet_V3.pdf",
      "datasheet_version": "V3.0",
      "specimen": {
        "infill_percent": 100,
        "nozzle_c": 260,
        "bed_c": 80,
        "speed_mm_s": 200,
        "conditioning": "annealed and dried at 80 °C for 12 h",
        "orientation_note": "X-Y: bars printed flat; Z: bars printed upright (across the layers)"
      },
      "properties": [
        {"property": "density", "direction": "", "value": 1.05, "unit": "g/cm3", "standard": "ISO 1183"},
        {"property": "tensile_modulus", "direction": "XY", "value": 2200, "plus_minus": 190, "unit": "MPa", "standard": "ISO 527"},
        {"property": "tensile_modulus", "direction": "Z", "value": 1960, "plus_minus": 110, "unit": "MPa", "standard": "ISO 527"},
        {"property": "tensile_strength", "direction": "XY", "value": 33, "plus_minus": 3, "unit": "MPa", "standard": "ISO 527"},
        {"property": "tensile_strength", "direction": "Z", "value": 28, "plus_minus": 2, "unit": "MPa", "standard": "ISO 527"}
      ],
      "notes": ""
    }
  ]
}
```

- `type`: the Filamatch filament type (PLA, PETG, ABS, ASA, PC, PA-CF,
  PETG-CF, ...), as `Filamatch/data/filament_rules.json` names it. When the
  rules have no name for it, the exact name (PC-ABS, PET-GF, PPS-GF): never
  a near one, because a glass fibre is not a carbon fibre.
- `aliases` (optional): other names of the same product, without the
  maker, as catalogs and slicer presets spell them ("ABS PolyLite" for
  PolyLite ABS). Add one only when it is surely the same product: the same
  data sheet, or the only product of that kind the maker sells. The
  printed values find a filament by its exact name or one of these.
- `specimen`: how the maker printed the test bars. Other print settings the
  sheet names go in too (`chamber_c`, `shells`, `top_bottom_layers`,
  `cooling_fan`).
- `property`, one of: `density`, `tensile_modulus`, `tensile_strength`,
  `yield_strength`, `elongation_at_break`, `flexural_modulus`,
  `flexural_strength`, `impact_strength` (unnotched),
  `impact_strength_notched`, `heat_deflection_045` (°C at 0.45 MPa),
  `heat_deflection_18` (°C at 1.8 MPa), `vicat_softening`, `shore_hardness_a`,
  `shore_hardness_d`, `water_absorption`.
- `direction`: `XY` (along the layers), `Z` (across the layers), `XZ`/`YZ`
  when the sheet says so, or `""` when it gives none.
- `unit`: as the sheet gives it (`MPa`, `GPa`, `%`, `kJ/m2`, `°C`, `g/cm3`).
- `plus_minus`: the spread the sheet gives, else left out.
- `standard`: the test standard the sheet names (ISO 527, ASTM D638, ...),
  as printed, also when it looks wrong (the notes say so).
- `condition`: `dry` or `conditioned` (moist), only when the sheet gives
  both for a nylon.
- `notes`: anything that changes how a value must be read (dry or
  conditioned nylon, annealed or not, molded instead of printed bars), and
  any error on the sheet.

## Rules

- Every value is copied from the maker's sheet, never from memory or from
  another product. A value the sheet does not give is left out.
- An obvious typo on a sheet is not used: the notes say what the sheet
  prints.
- After a change, run `python3 scripts/datasheet_docs.py`. It checks every
  record and writes the table below. `tests/run_all.py` runs the same check.
- Data sheets change. Look for a newer version before you add values, and
  keep `datasheet_version` and `accessed` current.
